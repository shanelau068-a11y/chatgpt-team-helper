# chatgpt-team-helper：项目运行与AI接手

Vue与Node工作区构成的Team账号管理平台Fork，含订单渠道、兑换、后台和外部集成。

## 仓库身份

- 分类：服务与部署；类型：node。
- 默认分支：`main`；当前可见性：公开。
- 本说明针对本仓库当前文件；历史本机绝对路径与相似项目不能作为当前运行位置。

## 数据与搬迁

后端SQLite、JWT_SECRET、渠道授权、机器人Token与浏览器状态不随源码备份。启动会初始化数据库和多个调度器，正式运行前逐项配置。

## 怎么验证

先执行 [验证记录](VERIFICATION.md) 所列命令，再按改动检查实际页面或输出。没有测试脚本时不能把占位npm test当作通过。仅文档更改检查链接和路径；涉及数据、几何、金额或接口的修改运行相应回归测试。

- 本轮完成Vue类型检查与前端构建；后端含实际邀请、机器人与订单调度，未用真实账号启动这些行为。
- 保留上游许可证和来源；先读SECURITY.md与OPEN_SOURCE_CHECKLIST.md，再配置生产部署。
